# 安全与合规基线

最后核验：2026-07-18

本文是 R0 阶段的初始威胁模型与许可证基线，不是完成的安全评估、法律意见、SBOM、漏洞审计或发布合规结论。所有控制仍须随实现、固定依赖、具名真机和华为应用市场最终制品形成证据。

## 信息状态与范围

- **当前实测**：仓库当前仍以研究文档为主，尚无可供完整审计的客户端实现、HAP、固定依赖锁或 SBOM。当前R0正式基线已采用 NetBird v0.74.7；既有许可证识别和依赖分析仍绑定其实际核对的 v0.74.6，不因版本采用自动升级为 v0.74.7 结论。
- **方案建议**：以下资产、边界、威胁和缓解措施是首轮工程必须落实和验证的安全基线。
- **尚未验证**：平台安全存储、VPN fd 与 `protect`、跨语言内存与线程安全、签名、市场重签、服务端部署和全部许可证义务尚未形成端到端证据。

## 资产

- 测试网络专用 setup key、后续 token、注册状态和凭据轮换材料。
- 节点长期私钥、短期会话或协议密钥及其派生材料。
- VPN 虚拟接口 fd、路由、DNS、MTU、外层 socket 和 `protect` 状态。
- management、signal、relay、peer 拓扑、routes、DNS 配置和网络流量。
- ArkTS、native 与 Go 之间传递的字符串、缓冲区、fd、回调和错误状态。
- HAP、App Pack、native 库、服务端镜像、依赖锁、SBOM、provenance 和制品哈希。
- ArkTS 应用壳源码、资源、Ability/ExtensionAbility 配置、权限声明和构建产物。
- ohpm 直接与传递依赖、锁文件、registry 来源、完整性校验和安装缓存。
- npm/pnpm 直接与传递依赖、锁文件、registry 来源、完整性校验和安装缓存。
- Hvigor 及其插件、构建脚本依赖、插件配置、缓存和可执行入口。
- 开发、测试和发布签名密钥、证书、华为账号与渠道权限。
- 用户诊断、应用日志、崩溃信息、抓包、设备标识和支持矩阵证据。
- Huawei 工具、SDK、Emulator、镜像、Go 工具链及其来源、版本、许可与归档记录。

## 信任边界

- 用户交互与 ArkUI 应用状态之间的边界，包括 setup key 输入、VPN 授权、注销和诊断同意。
- ArkTS 应用壳、VpnExtensionAbility、native/NAPI 桥接和 Go/NetBird 核心之间的跨语言与跨线程边界。
- 应用进程、系统 VPN 服务、虚拟接口 fd、受保护外层 socket 与普通网络之间的边界。
- 客户端与自托管 management、signal、relay、测试 peer 及 DNS/route 目标之间的网络边界。
- 开发 Pod、持久化 HOME、临时 overlay、构建缓存、CI runner、制品库和证据存储之间的供应链边界。
- ArkTS 应用壳与 ohpm、npm/pnpm、Hvigor 插件依赖解析、下载、缓存和锁定之间的包管理供应链边界。
- 开发签名、测试签名、发布签名、华为应用市场上传和市场重签最终制品之间的发布边界。
- 项目控制的源码与 NetBird、Go、WireGuard、Huawei SDK/工具及未来第三方依赖之间的上游边界。

## 攻击者与失效主体

- 能诱导用户输入恶意配置、泄露 setup key 或批准非预期 VPN 操作的远程攻击者。
- 能控制不可信网络、DNS、peer、relay 或中间路径并实施窃听、篡改、重放、降级和流量分析的攻击者。
- 获得普通应用权限、日志访问、设备备份或部分本地文件访问能力的恶意应用或本地用户。
- 控制或入侵测试 management、signal、relay、peer、构建 runner、依赖源或制品库的供应链攻击者。
- 因实现缺陷导致越界访问、use-after-free、重复关闭、线程竞态、密钥残留或绕过 `protect` 的非恶意失效主体。
- 获得过宽账号、签名或市场权限，或误操作日志、制品和发布流程的内部角色。

## 威胁、缓解与待验证

| 领域与威胁 | 初始缓解基线 | 待验证证据 |
| --- | --- | --- |
| setup key/token 被日志、命令历史、进程参数、UI 状态、崩溃或证据泄露，或被重复使用 | 使用测试网络专用、最小权限、可撤销且有期限的 setup key；通过受控输入注入；禁止回显和归档；注册后尽快撤销或轮换；注销清理关联状态 | 输入组件、进程与日志扫描、服务端撤销、轮换、注销和泄露响应证据 |
| 节点私钥或其他长期密钥明文持久化、进入备份或可被普通应用读取 | 长期密钥禁止明文持久化，必须使用经具名真机验证的平台安全存储或硬件派生保护；限制导出、备份和访问范围；销毁时验证不可恢复 | 目标 SDK 能力、具名真机存储位置、访问控制、备份行为、轮换和删除测试 |
| 短期密钥、派生材料或明文凭据在堆、跨语言副本、swap、crash dump 中残留 | 短期密钥只存在于受控内存，限制副本和生命周期，使用后显式清除；敏感缓冲区不进入普通字符串、日志或诊断 | ArkTS/native/Go 各层内存模型、优化器行为、crash 路径和清除测试 |
| VPN fd 所有权不清导致泄漏、重复关闭、fd 复用攻击、路由残留或流量旁路 | 为创建、复制、移交、使用、关闭和异常清理定义单一所有权契约；校验 fd 类型与生命周期；对 crash、kill、撤权和重启执行清理 | native 数据泵与 Go/WireGuard 的 fd 测试、故障注入和资源观测 |
| management、signal、relay 或 peer 外层 socket 未及时 `protect`，造成递归入隧道、断连或流量误路由 | 枚举所有首次与重连 socket 类型，在建连所需时点逐一调用目标 SDK 证明的 `protect`；失败时 fail closed 并可诊断 | 目标 SDK/头文件、最小样例、具名真机 direct/relay/重连和抓包证据 |
| ArkTS/native/Go 跨语言边界发生越界、UAF、竞态、panic 穿透、回调到已销毁对象或敏感副本扩散 | 固定 ABI；明确字符串、缓冲区、fd、线程和回调所有权；边界校验长度与状态；隔离 panic/异常；执行模糊测试、竞态测试和重复启停 | 两向调用、异步回调、异常回收、sanitizer/模糊测试和真机复现证据 |
| 日志与诊断泄露凭据、私钥、拓扑、设备标识、流量内容或用户行为 | 默认最小日志；源端过滤加归档前扫描；使用稳定假名；诊断必须由用户明确选择加入；执行证据 schema 的脱敏与保留期 | 自动秘密扫描、人工抽查、用户同意流程、到期删除和污染响应演练 |
| 固定工具链或归档被替换、来源混淆、缓存投毒，或归档行为超出许可 | 固定版本、来源、大小和 SHA-256；隔离稳定与 Beta 链路；受控存储与最小访问；构建前校验；只在许可明确允许时归档或内部再分发 | 工具链 provenance、重建校验、访问审计、许可文本适用性和删除流程 |
| ArkTS 应用壳、ohpm、npm/pnpm 或 Hvigor 插件依赖被投毒、替换、来源混淆、锁文件漂移，或引入恶意/未审查包并进入构建与运行路径 | 固定 registry 与来源策略；锁定直接与传递依赖版本；校验锁文件、完整性摘要和 provenance；最小权限安装；禁用隐式升级；审查新增插件与生命周期脚本；隔离缓存并在 CI 使用可重放安装 | ohpm/npm/pnpm/Hvigor 锁文件与 registry 配置、依赖树与 SBOM、安装与构建可重放证据、插件与生命周期脚本审查、缓存隔离和篡改检测 |
| 开发/测试/发布签名混用、私钥泄露、权限过宽或签名制品被替换 | 分离签名信任边界；密钥不进仓库、缓存和日志；使用 KMS/HSM、最小权限、双人控制、轮换与吊销；签名前后记录制品哈希 | 实际账号与角色、签名环境、恢复/轮换/吊销演练和审计记录 |
| 华为应用市场重签后的最终制品与候选制品代码、权限或行为不一致 | 获取市场最终制品，记录其哈希、签名和权限，重新执行安装、升级、VPN 授权、联网、安全与完整回归；不复用上传前结论 | 市场账号、审核、重签、下载、验签、差异分析和具名真机证据 |
| 自托管测试 management/signal/relay 被入侵、配置漂移、混入生产数据或扩大网络访问 | 使用与客户端固定同版本的隔离测试环境；专用 setup key、最小网络权限、受控 peer、配置与镜像哈希、补丁和漏洞管理；不使用生产身份或数据 | 部署清单、版本与哈希、网络隔离、访问审计、备份恢复、升级和事件演练 |

任何秘密泄露、长期密钥明文持久化、短期密钥未按生命周期清除、未受保护的必需外层 socket 或市场最终制品完整性异常均阻断对应阶段晋级，并按影响执行凭据轮换、证据作废和事件处置。
