我们在开发 **HarmonyOS 平台的自研 NetBird 客户端**（非官方客户端），上一把一次性 setup key **已被真机登录消费**（`usage_limit = 1`，注册成功，peer 主机名 `ohos-smoke-1`，overlay 地址 `100.108.144.165`，用于登录烟测）；现在我们需要**新的第二把**一次性 setup key，用于下一步在**真机上启用客户端的中继（relay）路径**并观察状态。

## 重要约束

- **key 不要落库**：请**不要**把它写进任何代码仓库、公开渠道或工单系统附件。

- **上次的设备**：上一次注册的 `ohos-smoke-1` 可能仍留在 peer 列表里，**是否清理由你们决定**；若方便，请顺带告知它**是否仍在 peer 列表**（我们会在验证收尾时一并申请删除）。
