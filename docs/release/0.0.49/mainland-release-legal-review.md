- 应用主名称为 `NetBird`；首页、关于及托盘未见非官方声明，README 与商店草稿已有。商店登记名 `Netbird`、包名 `cn.alfadb.netbird`、AppID `6917608953844302724` 不构成品牌授权。
- 实际应用/托盘共用橙色鸟形 PNG，其来源、原始资产许可及授权尚未核清；现有材料不能证明它就是官方图，也不能证明必然无授权。

- 许可原文、版权/免责及修改声明随包提供、精确对应源码公开获取尚未全部落实；应用内隐私政策与许可证入口仍缺。运营主体、邮箱和政策 URL 按用户决定暂缓填写。

## 风险条件

- **名称与来源混淆：**现行 2019 年修正商标法按来源识别、核准商标/商品和混淆等条件判断；大陆有效注册及在先权检索未完成，不能声称“已查无商标”。直接用同类产品的 `NetBird` 作主名称有来源或授权混淆风险；改大小写、加 HarmonyOS 后缀、加非官方声明、免费或开源均不自动免责。
- **现行法时间：**2026 年修订商标法第 87 条规定 2027-01-01 生效；截至本基准日，不能提前适用其新增指示性使用条款，也不能混用新旧条号。发布跨该日期时应重新核法。
- **授权边界：**NetBird Press Kit 明示为 media use，未确认第三方应用主品牌的通用授权。上游 BSD-3-Clause 允许符合条件的代码再分发，不授予商标权；版权、条件、免责保留及非背书要求仍须遵守。真实适度的兼容性描述须结合整体展示判断，不能一概要求事先书面授权。
- **开源与渠道：**AGPL 要求适用许可/声明及精确对应源码；不能只给最新分支或本地提交。还须按实际分发条件核附加限制、修改版安装控制及安装信息义务，不能仅凭手机签名推断须交发行私钥。华为开发者服务协议 4.5 仅针对华为提供的开源组件；实际适用的附加分发协议、EULA、签名/DRM 完整证据尚缺，不能断言 AGPL 与华为相容或不相容。
- **分发与经营：**按上述客户端软件提供边界，不能将我方等同跨境网络服务运营商；是否涉及特定经营资质须按实际活动判断。个人/公司身份、网络服务经营及品牌/开源权利分别核对，企业账号不是行业许可证。国内软件分发仍须核对品牌、著作权许可、实际 APP 备案、隐私及平台条件，不因个人、开源、免费或不经营网络服务承诺免监管。若以后售卖连接、代运营接入或提供跨境服务，应按真实业务重核。
- **华为审核：**50104 第 13 章第 16 项针对未经批准利用专线/VPN 信道开展跨境经营的内容，第 27 项涉及动态 IP 代理；加速器另有条件，不能直接套用于全部私有组网客户端，不能据此说“VPN 一律非法”或“必须企业账号”。
- **隐私与数据流：**仅大陆分发不保证不调用境外服务。应按实际 IP、设备/账号、日志、管理端、IdP、中继等数据流，确认开发者、组织管理员及服务方角色，落实告知、处理依据、安全与适用出境要求；不能仅因用户自行配置服务器就声称零收集或一律免除义务。

## 发布前处理项

1. **品牌方案由用户选择（仅建议，未实施）：**优先独立自有主名称与自有图标，在次要说明真实、适度写“兼容 NetBird 的非官方私有组网客户端”，明确真实开发者及无官方关联；最终新名仍须检索在先权并核整体展示。
2. 如保留 `NetBird` 主品牌或使用官方图，建议取得明确涵盖中国大陆、华为 phone/PC 渠道、具体名称/图形、免费/收费及声明范围的书面授权，并核授权主体权限。此前仅询问是否提 GitHub issue 不构成发帖授权；其后用户明确“那就先走Discussions”，已由 alfadb 于 2026-10-16T03:54:10Z 在官方 Q&A / Support 创建唯一[请求 #8228](https://github.com/netbirdio/netbird/discussions/8228)，并独立读回核验 title/body/author/category。请求已发，尚未取得名称/Logo 许可，也不代表接受合同或获得上架批准；收费与发布主体未最终决定。现名称、图标、源码 repoAppID/包名与 APP ID 维持现状，不删除重建。
3. 按最终发行包补全 AGPL 原文、上游及依赖版权/许可/免责、修改声明和适用界面通知；提供可公开获取的精确对应源码及必要构建脚本，在发行入口明确指向并验证可获取性；继续处理两项表达式缺口与最终来源/链接范围。
4. 取得本账号、地区和产品实际适用的华为附加分发协议、EULA、签名/DRM 条款，再逐项核 AGPL；现有协议片段不足以给兼容性结论。
5. 按已明确的仅提供客户端软件边界及最终实际活动，确认 APP/相关网站备案和确实适用的资质；收费与发布主体待定，不虚列强制行业许可。发行前核对默认配置与声明一致：首装管理 URL 默认值已在源码清空、相关 145 项自检通过并保留已存配置，但未加入已装 `37e881e` 包，也未完成首装/注销真实 UI 验证；基础 VPN 配置仍含第三方 DNS 回退，详见[隐私草案](privacy-policy-draft.md)。
6. 待用户恢复提供主体、邮箱、政策 URL 后，按真实数据流完成政策及联系渠道，使平台与应用内均可访问；草案存在不能替代产品落实。最终材料交国内专业人士审查，处理结论后再决定公开发布。
