# DRAFT 待确认：Netbird 隐私政策草案

**本文件不是已生效政策，不可直接作为正式隐私政策发布。** 适用于 0.0.49 候选的内容核对；不填写生效日期或联系地址。运营主体、支持/隐私邮箱、对外政策 URL 和地区统一在[准备状态表](release-readiness.md)填写确认后，再形成正式政策。

## 应用与服务

Netbird 是面向用户自行搭建的 NetBird 网络的 HarmonyOS 非官方客户端，仅限异地组网工具使用。客户端开发者提供软件，不运营或提供网络接入、线路、管理平台、信令、中继/代理等网络服务；由用户自行部署、配置和管理其组网及相关服务。客户端软件发布主体为[待确认]，与用户所选组网服务运营者的角色分开；相关管理服务、身份提供方及网络服务各自负责其服务中的数据处理，账户体系由相关组网服务或身份提供方（IdP）负责。客户端中的信息处理仍按下述实际数据流说明。

## 处理的信息、用途与去向

| 信息 | 用途及处理位置 |
| --- | --- |
| 管理服务地址、设备私钥、连接偏好 | 在应用私有存储保存，用于识别设备并建立、恢复连接；私钥属于敏感凭据，应保护设备及备份 |
| Setup Key | 用户选择该方式时在本机单独文件保存，并用于向所选管理服务注册设备 |
| SSO登录信息 | 在身份提供方页面完成认证；按其配置使用 id_token 或 access_token 形成当次注册或延长会话所需 JWT，应用业务代码不持久保存该 JWT |
| 设备公钥、注册凭据及节点元数据 | 提供给用户选择的管理服务，完成注册、授权和网络配置同步；节点元数据可含主机名、系统/客户端版本等字段 |
| 对端和网络信息 | 处理对端公钥、名称、IP、端点、连接状态、路由和 DNS 配置，以建立组网连接并展示状态 |
| 本地运行与诊断日志 | 记录状态、连接、IP、节点、网络情况及系统 crash/freeze 等诊断事件，用于排障；用户可主动导出日志文件 |

SSO 使用的 ArkWeb 可能依平台及身份站点行为产生 cookie、缓存等数据；JWT不由应用业务代码落盘，不代表这些浏览数据不存在。身份提供方决定其账号、认证记录及保留规则。

应用会按所选部署及下发配置联系管理、signal、对端、STUN、中继和 DNS 服务；管理配置的 DNS 与物理网络 fallback 也可能接收解析请求。当前基础 VPN 配置含 Google Public DNS（8.8.8.8）作为回退，是否使用取决于最终生效配置：ready 的本地 resolver / 下发 DNS 配置优先，没有可用配置时可能回到基础值。这是配置阶段回退，不表示私域解析请求失败后会自动转发 Google。第三方服务并非我方运营，实际处理地域需按服务和部署核对；不能保证一切节点均由用户自建或全程境内。实际服务位置、接收方和跨境情况还取决于用户及其组织的网络配置，不能用固定项目服务器名单概括。经出口节点访问的流量受该出口服务的处理规则影响。

## 存储、保留与用户操作

设备配置和 Setup Key 存放于应用私有存储。当前实现没有为这些文件增加应用层加密，不能将其描述为 AssetStore 或 AES 加密保存。

当前源码的 UI 日志预算为约 4 MiB，VPN/native 日志预算为约 96 MiB，以轮转方式覆盖旧记录；单条尾记录可能略超段上限。该数值不等于系统诊断记录、导出副本或全部应用数据的总上限。导出副本保存于用户选择的位置，由用户自行保管、删除；分享前应检查并脱敏网络信息。

用户可断开 VPN 停止当前隧道连接。使用注销/清除配置操作会清除本机设备私钥和配置；在线时先尝试从管理服务移除本设备，失败或超时仍继续本地清除；离线时仅清本地，管理端设备记录可能保留。清除本机配置不等于注销 SSO 或管理服务账户，也不等于删除已导出日志。账户注销及服务端数据请求应联系用户所选身份提供方或管理服务；应用隐私联系邮箱为[待确认]。

## 权限与第三方组件

应用声明互联网访问以联系网络服务，读取网络状态以识别物理网络和 DNS，后台运行以申请连接期间的长时任务，以及应用终止准备以在适用设备上处理退出清理。VPN 的授权和运行受系统机制控制；后台任务不保证永久在线。日志导出通过系统文件选择器由用户选定位置。

最终包实际 SDK、第三方组件名称、用途、信息处理及其政策链接需由依赖盘点补齐后核定；此稿不声称零收集或绝无上报。限定源码搜索未见 analytics 服务不能替代完整审计。确认后的政策变更与隐私请求渠道应在公开政策 URL 提供。
