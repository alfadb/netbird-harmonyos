# netbird-harmonyos

`netbird-harmonyos` 是一个面向 HarmonyOS NEXT 的 NetBird 客户端项目。本项目独立开发、非官方维护，目前处于早期开发阶段。

## 项目状态与目标

项目目标是在 HarmonyOS NEXT 上探索并实现可用的 NetBird 客户端，逐步完成平台适配及与 NetBird 网络服务的集成。

当前仓库尚未提供可用发行版本，功能范围、技术方案和平台能力适配仍在验证中。

## 开发状态

项目处于早期开发阶段，接口与实现可能发生较大变化。现阶段不应将其用于生产环境。
